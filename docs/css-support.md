# CSS support

This file is generated by `tools/adw-css-props` from `tools/adw-css-props/properties.yaml`.
Do not edit it. A test fails when it is stale.

The engine supports the CSS that libadwaita's `gtk.css` and an application's `style.css` use.
It follows GTK 4.24 where GTK and the CSS specifications disagree.
